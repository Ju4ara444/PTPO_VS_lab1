\## 📋 Что делает программа



1\. \*\*Подсчёт уникальных слов.\*\* Программа читает четыре тома «Войны и мира»

&#x20;  и выводит каждое уникальное слово с количеством вхождений:

&#x20;  ```

&#x20;  слово - счётчик

&#x20;  ```

2\. \*\*Индексация позиций.\*\* Для каждого слова показывает номера позиций,

&#x20;  на которых оно встречается в файле:

&#x20;  ```

&#x20;  слово1 – позиция №1, позиция №2, …

&#x20;  ```

3\. \*\*Работа с `vector<int>` через алгоритмы STL:\*\*

&#x20;  - \*\*3а.\*\* Простые числа заменяются на их квадраты.

&#x20;  - \*\*3б.\*\* Сортировка: сначала нечётные по возрастанию, затем чётные по убыванию.

&#x20;  - \*\*3в.\*\* Поиск уникальных чисел в заданном диапазоне.



Дополнительно: программа в цикле ищет любое слово, введённое пользователем,

и показывает позиции этого слова в каждом файле.

\## 🚀 Как собрать и запустить



\### Требования

\- Visual Studio 2019 или новее (или MSVC 2017+)

\- Windows (используется `<windows.h>` для настройки кодировки консоли)



\### Сборка в Visual Studio

1\. Открыть `PTPO\_lab1.slnx`.

2\. Убедиться, что в \*\*Свойствах проекта\*\*:

&#x20;  - \*\*Свойства конфигурации → Отладка → Рабочий каталог\*\* = `$(ProjectDir)`

&#x20;  - \*\*Свойства конфигурации → Дополнительно → Набор символов\*\* = \*Многобайтовая кодировка\*

3\. Собрать: \*\*Ctrl + Shift + B\*\*.

4\. Запустить: \*\*Ctrl + F5\*\*.



\### Сборка через командную строку (g++)

```bash

g++ -std=c++11 -o lab1 main.cpp poisc\_slov.cpp

./lab1

```

> На Linux/macOS потребуется убрать `#include <windows.h>` и вызовы

> `SetConsoleCP`/`SetConsoleOutputCP`.

\## 🧩 Использованные контейнеры и алгоритмы STL



| Контейнер / алгоритм | Где используется | Зачем |

|---|---|---|

| `std::string` | Везде | Хранение слов |

| `std::map<string, int>` | `countWords` | Слово → количество (с автосортировкой) |

| `std::map<string, vector<int>>` | `getWordPositions` | Слово → позиции |

| `std::vector<int>` | Этап 2, 3 | Позиции и числа |

| `std::sort` | Этап 3б, 3в | Сортировка |

| `std::reverse` | Этап 3б | Переворот для убывания |

| `std::ifstream` | Этап 1, 2 | Чтение файлов |



\## 📚 Ключевые моменты реализации



\- \*\*Кодировка консоли\*\* настроена через `SetConsoleCP(1251)` и

&#x20; `SetConsoleOutputCP(1251)` — иначе русский текст отображается крокозябрами.

\- \*\*Порядок `#include`:\*\* `<windows.h>` подключается \*\*после\*\* стандартных

&#x20; заголовков и \*\*до\*\* `using namespace std`. Иначе возникает конфликт

&#x20; `Windows byte` и `std::byte` (59 ошибок компиляции).

\- \*\*`vector<int>\&`\*\* в функциях 3а, 3б — передача по ссылке, чтобы

&#x20; изменять исходный вектор, а не копию.

\- \*\*Позиция слова\*\* — номер слова, начиная с 0 (как в задании).



\## 📝 История разработки



Проект делался поэтапно, каждый этап — отдельный коммит:



| Коммит | Что сделано |

|---|---|

| `Этап 1: подсчёт слов, поиск в цикле, настройка кодировки` | Задание 1 + поиск + вывод |

| `Этап 2: индексация позиций слов в файле` | Задание 2 |

| `Этап 3: работа с vector<int>` | Задание 3 (а, б, в) |



Такой подход позволил видеть прогресс и при необходимости откатываться

к предыдущему рабочему состоянию.
